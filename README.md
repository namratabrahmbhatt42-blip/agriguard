# AgriGuard 🌾

AI-powered multi-agent farming assistant for Indian farmers. Free to use, no signup required.

## Agents
- 🌦 **Weather Agent** — real live weather data and farming advice
- 🌿 **Crop Doctor** — crop disease diagnosis and remedy
- 📊 **Market Agent** — live mandi prices across India
- 🤖 **Orchestrator** — smart routing between agents

## Features
- Supports English and Hindi
- Farmer memory across conversations
- Security guardrails against prompt injection
- Real weather data via OpenWeatherMap MCP server
